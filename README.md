# Mango Land Tours Website

Official website project for Mango Land Tours, a Sri Lankan tour company.

## Website

Live site: https://mango-land-tours.gemnadsolutions.chatgpt.site/

## Project structure

The production-ready static website is in the `dist/` folder. Open `dist/index.html` through a local web server or deploy the contents of `dist/` to any static hosting provider.

The site includes tour itineraries, destination pages, driver-led transport options, a tour finder, a detailed trip enquiry form, guide information, and review links.
